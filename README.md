## FAQ:

### Q1: How do I download the files?
A: If you're not familiar with Git and just want to download the entire solution, click the green button saying "Code", and then select "Download ZIP". If you know some Git, just clone this repository to your machine.

### Q2: How do I open those files?
A: Simply open the LibraryManagement.Api.slnx file in Visual Studio 2026 or VS Code.

### Q3: Which version of the code should I download?
A: This repository contains the **final version** of the code, as it looks at the end of the course. If you are in the middle of the course, it is better to use the code from the section you are currently working on. At the end of each section, you will find a link to the source code that shows the project exactly as it looks after that section.

Keep in mind that the final version requires more setup than the early ones. For example, it needs a running PostgreSQL database, which the code from the first sections does not use at all.

### Q4: How do I run the API?
A: In Visual Studio, right-click the LibraryManagement.Api project, select "Set as startup project", and click "Run" in the top menu. In VS Code or the terminal, go to the LibraryManagement.Api folder and run `dotnet run`. Once the API is running, you can test it with Swagger in the browser or with Postman.

### Q5: What do I need to run the API?
A: You need the .NET 10 SDK and a running PostgreSQL server. Before running the API, check the connection string in the appsettings.json file and adjust it to your local PostgreSQL setup (host, port, username, and password).

### Q6: Do I need to use AI tools to follow the course?
A: No. AI tools are optional in this course. All the code in this repository works the same no matter if you write it by hand or with the help of an AI assistant.
